Кликабельная оргструктура  /  

каталог экспертизы (Central Services Navigator) на Sharepoint. 

 

Цель проекта: 

Упростить доступ сотрудников BU к функциям Central Services, сделать прозрачным распределение ролей и ответственностей, а также обеспечить удобный способ коммуникации сотрудников BU с нужными специалистами. 

Задачи: 

Разработать интерактивную кликабельную оргструктуру Central Services в формате дерева. 

Разместить решение на странице SharePoint с использованием JAVA. 

Обеспечить возможность перехода от функции к конкретным сотрудникам и их контактам. Суть в том, чтобы не найти человека, а решить задачу.  Инструмент является средством коммуникации между пользователем и сотрудником CS по вопросам решения задачи, а не инструментом для её непосредственного выполнения. 

Обеспечить пользователям возможность находить сотрудников Central Services по функционалу или задачам без необходимости знать ФИО или контактные данные.

Функции Must: 

В центре отображается блок Central Services.

Страница каждой функции: 

По клику на функцию открывается дерево сотрудников, визуально расположенных по грейдам с PMами. 

В верхней части экрана есть плашка с правилами отправки запросов, которая может вместить три строчки с общими письмами функций по FAQ. После реализации инструмента и согласования с лидерами функций, будет предоставлено требование по тексту блока для каждой функции. 

Под каждой фамилией с фото отображается: 

специализация сотрудника, 

корпоративный e‑mail. 

При клике на e‑mail открывается окно Outlook для отправки письма. 

Группировка данных: 

Все сотрудники группируются по функции, в которой они работают. 

Источником данных является предоставленный Excel‑файл со списком сотрудников, функций, e‑mail и специализаций. 

Excel‑файл должен быть интегрирован в JAVA как база данных для построения структуры.

6. Требования к реализации: 

Использовать JAVA для визуализации дерева и обеспечения кликабельности элементов. 

Хранение и обновление данных должно быть связано с Excel‑файлом.
